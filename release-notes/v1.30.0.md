**Changed**
- **A clip's cut is in the downloaded file's name, and only there.** Type `1:13 to :55` as the cut when you download, and the clip arrives as `Some Title 1.13 to .55.m4a`, so the cut is in front of you while you make it. A file name can't hold a colon, so each one is written as a period. The cut follows the custom name when you typed one, and the source title when you didn't. The cut is made before the clip is processed, so the processed clip is named without it: `Some Title-44knorm-clipped-1dB.wav`. **Set Cut…** renames the file the same way, and **Change Cut…** replaces the cut in the name rather than adding a second one; the clip's block in the notes file follows it to the new name. The notes file and the row keep the cut with its colons. Because the name carries the cut, **Set Cut…** works in a temporary session and with Save clip notes off too, where it renames the file only. It can't be used while a clip is being analyzed or processed, as **Rename…** can't.
- **ClipHack always works in the newest episode.** The week's prep makes each episode folder, and ClipHack now points itself at the highest-numbered one: at launch, whenever you come back to it, and before each download. When prep makes next week's episode and clears this one out, ClipHack moves on its own instead of asking for a folder at the next download. Leaving a temporary session goes to the newest episode too.
- **A link whose clip has moved on is asked about before it is downloaded again.** ClipHack used to recognise a link only while the downloaded file sat in the folder under its download name. Processing trashes that file, and the clip skill renames and moves the processed one, so the same link pasted later was quietly downloaded again. Now the notes file decides: a file still in place is added to the list as before, and otherwise the popover says the link was already downloaded, and as what, and offers **Download Again**.

**Removed**
- **Person in clip.** The download popover no longer asks who is speaking.
- **Notes, and the X/Twitter post text.** The popover's Notes box, the post text fetched into it, and the notes shown under a row are gone. They were never saved, and the clip skill writes each clip's description from its transcript.
- **New Session, and choosing an episode or a download folder.** ClipHack makes no folders, and the session menu no longer lists episodes to switch between; the Destination row's **Change…** and **Reset** are gone with them. The menu names the current episode and keeps **Temporary Session** and **Choose Show Folder…**.
- **Reading notes files from before 1.29.** Per-clip notes files, session files with `---` between clips, 1.29.0's count line, and clips filed in a folder of their own are no longer read. Prep clears each episode's clips weekly, so none of those files is left.
