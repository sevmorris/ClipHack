**Changed**
- **The bundled FFmpeg is 9.0.2**, the newest line, up from 8.0.3. FFmpeg's 8.0 line has had no release since June, while 8.1 and 9.0 have had theirs in September, so the pin moves to the maintained newest line. ClipHack runs every downloaded and third-party clip through FFmpeg's file readers, so staying on a maintained line matters most here. Processing changes slightly for AAC in MP4, MOV and M4A, the most common downloads: FFmpeg 9.0 accounts for the AAC stream's padding differently, so these decode 59 samples (1.3 ms) shorter, and the level-ridden result moves by about −70 dBFS, with loudness and true peak unchanged. Every other format processes bit-identically to 1.25.9 (322 of 340 parity checks pass; the rest are those AAC timing differences). The source verified against FFmpeg's release signing key, the licence files are unchanged, and the build is still this project's own reproducible, LGPL, audio-only recipe, now revision r5 (`ffmpeg-deps-9.0.2-audio-arm64-r5`).
