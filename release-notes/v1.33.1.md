**Removed**
- **The Normalize & Limit preset.** Once noise reduction, the de-esser and leveling left the presets, it held exactly the settings of Broadcast Conform, which stays. Three built-in presets remain: Zoom 48 kHz, Broadcast Conform and Clean & Limit. Presets you saved yourself are unaffected.

**Documentation**
- **Help, README and manual say what loudness normalization really does.** They said it was always one fixed gain. FFmpeg applies one fixed gain only when it keeps true peaks under the ceiling; when it would push them over, typically on a quiet clip with sharp peaks, it normalizes dynamically instead.
- **Help corrections.** Its preset list left out Zoom 48 kHz, and it left Dynamic Leveling out of the pipeline. It said a reused link whose clip went to the Trash downloads again, where since 1.30.0 ClipHack asks first. It said output goes beside the source by default, where it goes to the newest episode's clips folder. It now also covers the Mono/Stereo and Left/Right controls and updates.
- **Manual corrections.** The session menu no longer lists episodes to switch between, as the manual still said. High-pass always runs, not only the limiter. Output goes to the episode's clips folder, and Choose… lasts until the next episode. The manual now covers Trash Originals, renaming, the file list's keys and the built-in presets.
- **README.** Its feature list covers sessions, cuts, uncut copies, per-clip channels, presets, Trash Originals and updates. It and the manual link 1.27.1, the last version for macOS 14, and describes how to run the tests and what `release.sh` does.
- The unreferenced screenshot of a long-gone version is removed.
