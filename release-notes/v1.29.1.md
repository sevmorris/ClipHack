**Changed**
- **The notes file no longer opens with a count of its clips and cuts.** 1.29.0 started the file with a line like `HT_0385 2026-10-13 · 20 clips · 2 cuts`. Nothing used the counts, and the file is already named after the session, so it now starts with the first clip. A file 1.29.0 wrote loses that line the next time ClipHack saves it; until then it is skipped, never read as a clip.

**Documentation**
- The manual's Clip Notes section shows the layout the notes file actually has, and covers clips added from disk and **Set Cut…**. It still described the layout from before 1.29.0.
